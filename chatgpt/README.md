# ASG Arbres Services Genève — site statique

Version de travail conçue comme une base prête à publier sur Cloudflare Pages, GitHub Pages ou un hébergement web classique.

## Contenu
- Accueil
- Services détaillés
- Réalisations / galerie
- Équipe / trombinoscope
- Notre approche et valeurs humaines/sociales
- Contact avec formulaire `mailto:` : aucun serveur SMTP ni backend nécessaire
- SEO de base : titres, descriptions, canonical, données structurées LocalBusiness, sitemap.xml, robots.txt
- Design responsive, couleurs forêt / mousse / automne, navigation mobile

## Important avant mise en ligne
Les photos utilisées dans cette maquette sont des images distantes de démonstration. Elles doivent être remplacées par les photos ASG dont vous détenez les droits, idéalement stockées localement dans `assets/images/`.

La page Équipe contient également des emplacements à compléter.

## Déploiement
Le dossier est autonome. Il suffit de publier son contenu sur un hébergement statique.

## Formulaire
Le formulaire prépare un e-mail avec `mailto:bendik.hauserman@bluewin.ch`. L'envoi est effectué par le logiciel de messagerie du visiteur, conformément au cahier des charges. Il n'y a donc ni SMTP, ni serveur applicatif, ni stockage des données du formulaire.
